- Power IT World Ltd (recycling services website)

## Tech
Plain HTML, CSS and JavaScript. No build step and no dependencies. Fonts load from Google Fonts.

## Run locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Push this repository to GitHub.
2. Go to **Settings > Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
4. Your site will be live at `https://<your-username>.github.io/<repository-name>/`.
